# AGENTS.md

## Objetivo

Este repositório contém exclusivamente a app VibeCheck. A aplicação ajuda uma pessoa a avaliar rapidamente uma ideia através de quatro perguntas e devolve um veredicto divertido e acionável.

## Limites

- Não colocar aqui código do portfólio nem de outras apps.
- O portfólio apenas deve apontar para a versão publicada desta app.
- Manter a experiência curta, divertida e utilizável sem conta.
- Não adicionar backend ou IA sem pedido explícito.
- Os dados pessoais permanecem no navegador do utilizador.

## Stack e validação

- React, TypeScript, Vite e CSS
- Desenvolvimento: `npm run dev`
- Tipos: `npm run check`
- Produção: `npm run build`

Qualquer alteração deve preservar a utilização em desktop e mobile e passar nos dois comandos de validação.
